# Frutos · modelo editorial v1.8

Un fruto es un relato voluntario de una acción, cambio o comprensión que la persona relaciona con un estudio de Dérej.

Flujo: Fuente → reflexión → práctica → acción → fruto → memoria.

Reglas:
1. El original permanece privado para moderación.
2. El editor puede abreviar/corregir, nunca cambiar el sentido.
3. La versión pública no incluye identidad técnica ni datos de moderación.
4. Ningún fruto se publica automáticamente.
5. La bitácora no usa likes, rankings ni conteos competitivos.
6. Los frutos son evidencia narrativa de aplicación reportada; no se presentan como prueba causal o científica de impacto.
